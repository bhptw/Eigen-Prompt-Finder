# Eigen-Prompt-Finder
Siemens Eigen Engineering Agent Plain Text Prompt Library

## Pages

- `index.html`: searchable engineering Prompt library.
- `scl-fb-html.html`: editable SCL FB / HTML simulation teaching Prompt, with copy, text download, select-all, reset and AI platform links. The full default Prompt is embedded in its textarea; edit that text to update it.
- `page-navigation.css`: shared page navigation styles. Links are relative for GitHub Pages project hosting.

The second page preserves the full Prompt from https://bhp-bob.my.canva.site/scl-fb-html. It runs in the browser without an AI API key or backend. Copy/download uses the current text; edits are not persisted after navigation. Theme preference is shared with the library.
